Protection contre les attaques API

Décrire les protections mises en place contre les attaques ciblant les API (OWASP API Security Top 10).

Menaces couvertes

  • Injection (SQL, NoSQL, LDAP, OS)
  • Broken Authentication
  • Broken Object Level Authorization (BOLA)
  • Broken Function Level Authorization (BFLA)
  • Mass Assignment
  • Excessive Data Exposure
  • SSRF
