DevSecOps

Le DevSecOps intègre la sécurité directement dans le cycle de vie du développement logiciel.

Pourquoi c’est important

  • Évite que les vulnérabilités atteignent la production en les détectant tôt dans le pipeline.
  • Intègre des contrôles de sécurité continus plutôt qu’un audit ponctuel en fin de projet.
  • Complète la gestion du cycle de vie et des tests déjà couverts pour les API et applications web.

Ce que cette section doit contenir

  • SDLC sécurisé : exigences de sécurité à chaque phase du cycle de développement. ISO A.8.25 · NIST PR.PS · CIS 16
  • CI/CD : pipelines protégés, artefacts signés, scan des images de conteneurs. ISO A.8.25 · A.8.32 · NIST PR.PS · CIS 16
  • SAST : analyse statique du code. ISO A.8.29 · NIST PR.PS · CIS 16
  • DAST : analyse dynamique en exécution. ISO A.8.29 · NIST PR.PS · CIS 16
  • Gestion des dépendances : SCA, SBOM, mises à jour des bibliothèques. ISO A.8.8 · NIST ID.RA · CIS 7 · CIS 16
  • Secrets management : coffre à secrets, rotation, détection de secrets dans le code. ISO A.5.17 · NIST PR.AA
  • Revue de code : revue par les pairs obligatoire, règles de codage sécurisé. ISO A.8.28 · NIST PR.PS · CIS 16
  • Security Gates : critères bloquants avant fusion et mise en production. ISO A.8.29 · A.8.32 · NIST PR.PS
  • Threat Modeling : modélisation des menaces (STRIDE) dès la conception. ISO A.8.27 · NIST ID.RA · CIS 16
  • Sécurité des environnements de développement : séparation dev / test / prod, données de test, accès au code source. ISO A.8.4 · A.8.31 · A.8.33 · NIST PR.PS
