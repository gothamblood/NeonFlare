PSI — Plan de secours informatique

Le PSI organise le secours PENDANT l’incident : bascule vers les moyens de secours pour maintenir les systèmes d’information critiques.

Contenu à inclure

  • Moyens de secours : site de repli (chaud, tiède, froid), redondance, capacité cloud. ISO A.5.30 · A.8.14 · NIST RC.RP
  • Procédure de bascule : déclenchement, étapes, responsables, durée cible compatible avec les RTO. ISO A.5.30 · NIST RC.RP
  • Mode dégradé informatique : services réduits disponibles pendant le secours. ISO A.5.30
  • Sauvegardes : copies disponibles sur le site de secours, cohérentes avec le RPO. ISO A.8.13 · NIST PR.DS · CIS 11
  • MCO des moyens de secours : mises à jour, supervision et capacité du site de secours. ISO A.5.30 · A.8.6 · NIST PR.PS
  • Tests de bascule : bascules réelles planifiées, mesure des délais. ISO A.5.30 · ISO 22301 cl. 8.5
  • Contrats de secours : fournisseurs de secours, engagements (MAO, SLA), SPOC. ISO A.5.20 · A.5.21 · NIST GV.SC

Rôle en GRC

PSI ≠ PRI : le PSI maintient le service pendant l’incident, le PRI rétablit les systèmes nominaux après.
