Gestion des incidents

Cette section décrit comment l’organisation réagit aux incidents de sécurité.

Journal des incidents

Contenu à inclure

  • Objectifs : limiter l’impact, restaurer les services.
  • Définitions : incident, événement, alerte.
  • Rôles : SOC, CISO, TI, utilisateurs. ISO A.5.24 · NIST GV.RR
  • Classification : mineur, majeur, critique. ISO A.5.25 · NIST RS.MA
  • Processus : Detect → Respond → Recover. ISO A.5.26 · NIST RS.MA · CIS 17
  • Communication : escalade, notifications. ISO A.5.26 · NIST RS.CO
  • Documentation : rapport d’incident. ISO A.5.28 · NIST RS.AN
  • Amélioration continue : post-mortem. ISO A.5.27 · NIST ID.IM

Rôle en GRC

La gestion des incidents protège l’organisation contre les interruptions et les pertes.
