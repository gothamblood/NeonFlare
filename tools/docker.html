Docker

ToolDescription
Images & build Build, list, inspect images
---- Common -----
[Build] — docker build -t <image>:<tag> .
[Build no cache] — docker build --no-cache -t <image>:<tag> .
[List images] — docker images
[Pull] — docker pull <image>:<tag>
[Remove image] — docker rmi <image>
[Prune dangling] — docker image prune -f
---- Inspect / audit -----
[Layers/history] — docker history <image>
[Full metadata] — docker inspect <image>
[Config only (jq)] — docker inspect <image> --format '{{json .Config}}'
Containers Run, exec, logs, lifecycle
---- Common -----
[Run detached] — docker run -d --name <name> <image>
[Run interactive] — docker run -it --rm <image> sh
[List running] — docker ps
[List all] — docker ps -a
[Logs] — docker logs -f <container>
[Exec shell] — docker exec -it <container> sh
[Stop] — docker stop <container>
[Remove] — docker rm -f <container>
---- Runtime inspection -----
[Resource usage] — docker stats --no-stream
[Filesystem diff] — docker diff <container>
[Processes] — docker top <container>
[Copy out] — docker cp <container>:/path ./local-path
Security scanning CVEs, secrets, misconfig in images
---- Trivy (image/filesystem scanning) -----
[Scan image] — trivy image <image>:<tag>
[High/critical only] — trivy image --severity HIGH,CRITICAL <image>
[Fail CI on findings] — trivy image --exit-code 1 --severity CRITICAL <image>
[Scan Dockerfile] — trivy config .
[Secrets scan] — trivy fs --scanners secret .
---- Docker Scout -----
[CVEs] — docker scout cves <image>
[Recommendations] — docker scout recommendations <image>
[Compare base image] — docker scout compare --to <other-image> <image>
---- Host hardening -----
[CIS benchmark] — docker run --rm -v /var/run/docker.sock:/var/run/docker.sock docker/docker-bench-security
[Find privileged containers] — docker ps -q | xargs docker inspect --format '{{.Name}} {{.HostConfig.Privileged}}'
[Find containers running as root] — docker ps -q | xargs docker inspect --format '{{.Name}} {{.Config.User}}'
Registry Login, tag, push
---- Common -----
[Login] — docker login <registry>
[Tag for registry] — docker tag <image> <registry>/<image>:<tag>
[Push] — docker push <registry>/<image>:<tag>
---- Signing / provenance -----
[Enable content trust] — export DOCKER_CONTENT_TRUST=1
[Sign & push] — docker trust sign <registry>/<image>:<tag>
Docker Compose Multi-container stacks
---- Common -----
[Up detached] — docker compose up -d
[Down] — docker compose down
[Rebuild] — docker compose up -d --build
[Logs] — docker compose logs -f
[List services] — docker compose ps
[Validate file] — docker compose config
