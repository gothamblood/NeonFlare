Terraform

ToolDescription
Core workflow init, plan, apply, destroy
---- Common -----
[Init] — terraform init
[Format] — terraform fmt -recursive
[Validate] — terraform validate
[Plan] — terraform plan -out=tfplan
[Apply plan] — terraform apply tfplan
[Apply directly] — terraform apply
[Destroy] — terraform destroy
[Target a resource] — terraform plan -target=<resource.address>
State Inspect, move, import, unlock
---- Common -----
[List resources] — terraform state list
[Show resource] — terraform state show <resource.address>
[Move (rename)] — terraform state mv <old.address> <new.address>
[Remove from state] — terraform state rm <resource.address>
[Import existing] — terraform import <resource.address> <id>
[Force-unlock] — terraform force-unlock <lock-id>
[Refresh] — terraform apply -refresh-only
---- Secrets in state -----
[Grep state for secrets] — terraform show -json | jq '..|.values?.password? // empty'
Security scanning Misconfig, policy, drift
---- tfsec / Trivy -----
[Scan directory] — tfsec .
[Scan (Trivy alias)] — trivy config .
[Fail CI on high] — tfsec . --minimum-severity HIGH
---- Checkov -----
[Scan directory] — checkov -d .
[Specific framework] — checkov -d . --framework terraform
[Skip a check] — checkov -d . --skip-check <CKV_ID>
---- Drift detection -----
[Plan (detects drift)] — terraform plan -detailed-exitcode
[driftctl] — driftctl scan
Workspaces & modules Environments, remote modules
---- Common -----
[List workspaces] — terraform workspace list
[New workspace] — terraform workspace new <env>
[Switch workspace] — terraform workspace select <env>
[Show outputs] — terraform output
[Show output (raw)] — terraform output -raw <name>
[Get modules] — terraform get -update
[Graph dependencies] — terraform graph | dot -Tpng > graph.png
