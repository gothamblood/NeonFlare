Kubernetes

ToolDescription
Cluster & context kubeconfig, nodes, namespaces
---- Common -----
[Current context] — kubectl config current-context
[List contexts] — kubectl config get-contexts
[Switch context] — kubectl config use-context <context>
[Cluster info] — kubectl cluster-info
[List nodes] — kubectl get nodes -o wide
[List namespaces] — kubectl get ns
[Set default namespace] — kubectl config set-context --current --namespace=<namespace>
Workloads Pods, deployments, logs, exec
---- Common -----
[List pods] — kubectl get pods -n <namespace>
[Pod details] — kubectl describe pod <pod> -n <namespace>
[Logs] — kubectl logs -f <pod> -n <namespace>
[Previous container logs] — kubectl logs --previous <pod> -n <namespace>
[Exec shell] — kubectl exec -it <pod> -n <namespace> -- sh
[Delete pod] — kubectl delete pod <pod> -n <namespace>
[Rollout status] — kubectl rollout status deployment/<name> -n <namespace>
[Rollback] — kubectl rollout undo deployment/<name> -n <namespace>
[Scale] — kubectl scale deployment/<name> --replicas=<n> -n <namespace>
RBAC & secrets Permissions, service accounts, secrets
---- Audit -----
[Can I do X?] — kubectl auth can-i <verb> <resource> -n <namespace>
[As another user] — kubectl auth can-i <verb> <resource> --as=<user>
[List roles] — kubectl get roles,clusterroles
[Role details] — kubectl describe clusterrole <role>
[List rolebindings] — kubectl get rolebindings,clusterrolebindings -A
[Service accounts] — kubectl get sa -n <namespace>
---- Secrets -----
[List secrets] — kubectl get secrets -n <namespace>
[Decode secret] — kubectl get secret <secret> -n <namespace> -o jsonpath='{.data}' | base64 -d
[Create from literal] — kubectl create secret generic <name> --from-literal=key=value
Security scanning Misconfig, CVEs, cluster hardening
---- kube-bench (CIS benchmark) -----
[Run benchmark] — kube-bench run --targets node,policies
---- Trivy (K8s + image scanning) -----
[Scan cluster] — trivy k8s cluster --report summary
[Scan namespace] — trivy k8s namespace <namespace>
---- Manual checks -----
[Privileged pods] — kubectl get pods -A -o jsonpath='{range .items[?(@.spec.containers[*].securityContext.privileged==true)]}{.metadata.namespace}{"/"}{.metadata.name}{"\n"}{end}'
[Pods running as root] — kubectl get pods -A -o jsonpath='{range .items[*]}{.metadata.name}{" "}{.spec.securityContext.runAsUser}{"\n"}{end}'
[Hostnetwork pods] — kubectl get pods -A -o jsonpath='{range .items[?(@.spec.hostNetwork==true)]}{.metadata.namespace}{"/"}{.metadata.name}{"\n"}{end}'
[Network policies] — kubectl get networkpolicies -A
Helm Package manager for Kubernetes
---- Common -----
[List releases] — helm list -A
[Install] — helm install <release> <chart> -n <namespace>
[Upgrade] — helm upgrade <release> <chart> -n <namespace>
[Rollback] — helm rollback <release> <revision>
[Dry run/diff] — helm upgrade --install --dry-run <release> <chart>
[Uninstall] — helm uninstall <release> -n <namespace>
