ExiftoolExtract metadata from files and images
---- Common -----
[Afficher toutes les métadonnées] — exiftool image.jpg
[Afficher un tag spécifique] — exiftool -FileName image.jpg
[Afficher plusieurs tags] — exiftool -FileName -DateTimeOriginal image.jpg
[Voir les types de tags] — exiftool -list
---- Extraction -----
[Extraire GPS] — exiftool -gps* image.jpg
[Extraire EXIF] — exiftool -exif:all image.jpg
[Extraire IPTC] — exiftool -iptc:all image.jpg
[Extraire XMP] — exiftool -xmp:all image.jpg
---- Modification -----
[Changer nom du fichier] — exiftool -FileName=new.jpg image.jpg
[Changer date] — exiftool -DateTimeOriginal="2020:01:01 12:00:00" image.jpg
[Ajouter un tag] — exiftool -Comment="Test" image.jpg
[Supprimer un tag] — exiftool -Comment= image.jpg
---- Suppression métadonnées -----
[Supprimer toutes les métadonnées] — exiftool -all= image.jpg
[Supprimer EXIF seulement] — exiftool -exif= image.jpg
[Supprimer GPS] — exiftool -gps:all= image.jpg
---- Export / Output -----
[Exporter JSON] — exiftool -json image.jpg
[Exporter XML] — exiftool -X image.jpg
[Exporter dans fichier] — exiftool image.jpg > meta.txt
---- Batch / Dossiers -----
[Scan dossier] — exiftool /path/dir
[Modifier tous les fichiers] — exiftool -Comment="Test" *.jpg
[Renommer selon date] — exiftool '-FileName[DateTimeOriginal]' *.jpg
---- Useful -----
[Voir structure EXIF] — exiftool -s -G image.jpg
[Voir tags inconnus] — exiftool -u image.jpg
[Voir tags système] — exiftool -ee image.jpg
theHarvesterGather emails, hosts, and names from OSINT
---- Common -----
[Scan simple] — theHarvester -d <domain> -b google
[Scan multi-sources] — theHarvester -d <domain> -b google,bing,duckduckgo
[Scan complet] — theHarvester -d <domain> -b all
---- Sources -----
[Google] — theHarvester -d <domain> -b google
[Bing] — theHarvester -d <domain> -b bing
[DuckDuckGo] — theHarvester -d <domain> -b duckduckgo
[Yahoo] — theHarvester -d <domain> -b yahoo
[LinkedIn] — theHarvester -d <domain> -b linkedin
[Twitter] — theHarvester -d <domain> -b twitter
[Shodan] — theHarvester -d <domain> -b shodan
[Certificats SSL] — theHarvester -d <domain> -b crtsh
---- Options utiles -----
[Limiter résultats] — theHarvester -d <domain> -b google -l 200
[Timeout] — theHarvester -d <domain> -b google -t 10
[DNS brute force] — theHarvester -d <domain> -b dnsbrute
[DNS reverse] — theHarvester -d <domain> -b dnsreverse
---- Output -----
[Output HTML] — theHarvester -d <domain> -b all -f report.html
[Output JSON] — theHarvester -d <domain> -b all -f report.json
[Output XML] — theHarvester -d <domain> -b all -f report.xml
---- API Keys -----
[Utiliser Shodan API] — theHarvester -d <domain> -b shodan -k <API_KEY>
[Utiliser Hunter.io] — theHarvester -d <domain> -b hunter -k <API_KEY>
---- Useful -----
[Voir les sources disponibles] — theHarvester -h
[Scan emails uniquement] — theHarvester -d <domain> -b all -e
[Scan hosts uniquement] — theHarvester -d <domain> -b all -h
MaltegoGraph-based OSINT visualization
---- Common -----
[Lancer Maltego] — maltego
[Transform sur un domaine] — Start Maltego and run transforms on <domain>
---- Transforms utiles -----
[Domain to DNS] — Transform: "To DNS Name - NS/MX/etc"
[Domain to Email addresses] — Transform: "To Email addresses"
[Person to Social Media] — Transform: "To Social Media Affiliations"
---- Export -----
[Exporter le graph] — File > Export > Export Graph to Image
SherlockFind usernames across social platforms
---- Common -----
[Recherche simple] — python sherlock.py username
[Plusieurs usernames] — python sherlock.py user1 user2 user3
---- Options -----
[Timeout] — python sherlock.py username --timeout 10
[Export CSV] — python sherlock.py username --csv
[Print found only] — python sherlock.py username --print-found
[Proxy] — python sherlock.py username --proxy http://127.0.0.1:8080
Google DorkingUse advanced search operators for OSINT
---- Common -----
[Site scope] — site:<domain>
[Admin panels] — site:<domain> inurl:admin
[Login pages] — site:<domain> inurl:login
---- Fichiers exposés -----
[PDF] — site:<domain> filetype:pdf
[SQL dumps] — site:<domain> filetype:sql
[Fichiers de config] — site:<domain> ext:env OR ext:conf
---- Autres -----
[Listing de dossier] — site:<domain> intitle:"index of"
[Sous-domaines] — site:*.<domain>
[Erreurs / stack traces] — site:<domain> "SQL syntax" OR "stack trace"
