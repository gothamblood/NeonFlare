Web Exploitation

ToolDescription
Burp SuiteIntercept, modify, and fuzz HTTP traffic
---- Common -----
[Lancer] — burpsuite
[Proxy navigateur] — Set browser proxy to 127.0.0.1:8080
---- Options utiles -----
[Intercept ON/OFF] — Proxy tab > Intercept is on/off
[Repeater] — Send request to Repeater (Ctrl+R)
[Intruder (fuzzing)] — Send request to Intruder (Ctrl+I), set payload positions
[Importer le certificat] — Browse to http://burp, download CA certificate
---- Automatisation -----
[Scan actif] — Target > right-click host > Scan
[Headless (CLI)] — burpsuite --project-file=proj.burp --config-file=config.json
sqlmapAutomated SQL injection exploitation
---- Common -----
[Scan simple] — sqlmap -u "http://<IP>/item?id=1"
[Dump base] — sqlmap -u "http://<IP>/item?id=1" --dump
---- Enumeration -----
[Lister les DB] — sqlmap -u "http://<IP>/item?id=1" --dbs
[Lister les tables] — sqlmap -u "http://<IP>/item?id=1" -D dbname --tables
[Lister les colonnes] — sqlmap -u "http://<IP>/item?id=1" -D dbname -T users --columns
---- Options utiles -----
[Avec cookie/session] — sqlmap -u "http://<IP>/item?id=1" --cookie="PHPSESSID=abc"
[POST data] — sqlmap -u "http://<IP>/login" --data="user=a&pass=b"
[OS shell] — sqlmap -u "http://<IP>/item?id=1" --os-shell
[Niveau/risque max] — sqlmap -u "http://<IP>/item?id=1" --level=5 --risk=3
WPScanScan WordPress for vulns and weak creds
---- Common -----
[Enumérer les users] — wpscan --url http://<IP> --enumerate u
[Scan complet] — wpscan --url http://<IP> --enumerate vp,vt,u
---- Options -----
[API token (vuln DB)] — wpscan --url http://<IP> --api-token <API_KEY>
[Brute force] — wpscan --url http://<IP> -U admin -P <wordlist>
[Plugins vulnérables] — wpscan --url http://<IP> --enumerate vp
[Thèmes vulnérables] — wpscan --url http://<IP> --enumerate vt
HydraBrute-force logins over many protocols
---- Common -----
[SSH bruteforce] — hydra -l user -P /path/pass.txt ssh://<IP>
[SSH userlist] — hydra -L users.txt -P pass.txt ssh://<IP>
[FTP bruteforce] — hydra -l user -P pass.txt ftp://<IP>
[HTTP Basic Auth] — hydra -l admin -P pass.txt <IP> http-get /admin
---- Web Forms -----
[HTTP POST form] — hydra <IP> http-post-form "/login:username=^USER^&password=^PASS^:F=incorrect" -L users.txt -P pass.txt
[HTTP GET form] — hydra <IP> http-get-form "/login?u=^USER^&p=^PASS^:S=Welcome" -L users.txt -P pass.txt
[CSRF token ignore] — hydra <IP> http-post-form "/login:usr=^USER^&pwd=^PASS^:H=Cookie: session=1" -L users.txt -P pass.txt
---- SMB / RDP -----
[SMB bruteforce] — hydra -L users.txt -P pass.txt smb://<IP>
[RDP bruteforce] — hydra -L users.txt -P pass.txt rdp://<IP>
---- MySQL / PostgreSQL -----
[MySQL] — hydra -l root -P pass.txt mysql://<IP>
[PostgreSQL] — hydra -l postgres -P pass.txt postgres://<IP>
---- Telnet / VNC -----
[Telnet] — hydra -l admin -P pass.txt telnet://<IP>
[VNC] — hydra -P pass.txt vnc://<IP>
---- Options utiles -----
[Threads] — hydra -t 32 -l user -P pass.txt ssh://<IP>
[Timeout] — hydra -l user -P pass.txt -W 3 ssh://<IP>
[Proxy] — hydra -l user -P pass.txt -e ns -p 8080 http-get://<IP>
[SSL] — hydra -l user -P pass.txt -S https-get://<IP>
---- Modes -----
[Try empty password] — hydra -l user -P pass.txt -e n ssh://<IP>
[Try username as password] — hydra -l user -P pass.txt -e s ssh://<IP>
[Try both] — hydra -l user -P pass.txt -e ns ssh://<IP>
---- Output -----
[Output file] — hydra -l user -P pass.txt ssh://<IP> -o result.txt
[Verbose] — hydra -v -l user -P pass.txt ssh://<IP>
[Debug] — hydra -d -l user -P pass.txt ssh://<IP>
ffufFast fuzzing of directories and parameters
---- Common -----
[Fuzz dossiers] — ffuf -u http://<IP>/FUZZ -w <wordlist>
[Fuzz avec extensions] — ffuf -u http://<IP>/FUZZ -w <wordlist> -e .php,.html,.txt
---- Filtres -----
[Filtrer par code] — ffuf -u http://<IP>/FUZZ -w <wordlist> -mc 200,301,302
[Exclure taille] — ffuf -u http://<IP>/FUZZ -w <wordlist> -fs 0
[Exclure mots] — ffuf -u http://<IP>/FUZZ -w <wordlist> -fw 1
---- Modes -----
[Fuzz un paramètre GET] — ffuf -u "http://<IP>/search?q=FUZZ" -w <wordlist>
[Fuzz un header] — ffuf -u http://<IP> -H "X-Forwarded-For: FUZZ" -w <wordlist>
[Fuzz vhost] — ffuf -u http://<IP> -H "Host: FUZZ.<domain>" -w <wordlist>
---- Options -----
[Threads] — ffuf -u http://<IP>/FUZZ -w <wordlist> -t 50
[Récursif] — ffuf -u http://<IP>/FUZZ -w <wordlist> -recursion
curlManual HTTP requests and response inspection
---- Common -----
[GET simple] — curl <URL>
[HEAD request] — curl -I <URL>
[Verbose] — curl -v <URL>
[Silent] — curl -s <URL>
---- POST -----
[POST form] — curl -X POST -d "user=chloe&pass=test" <URL>
[POST JSON] — curl -X POST -H "Content-Type: application/json" -d '{"id":1}' <URL>
[POST file upload] — curl -X POST -F "file=@image.png" <URL>/upload
---- Headers -----
[User-Agent custom] — curl -A "Mozilla/5.0" <URL>
[Add header] — curl -H "Host: admin.local" <URL>
[Cookie injection] — curl -H "Cookie: session=abc123" <URL>
[Auth Basic] — curl -u user:pass <URL>
---- SSL -----
[Ignore SSL errors] — curl -k https://<URL>
[Force TLS version] — curl --tls-max 1.2 https://<URL>
---- Output -----
[Save output] — curl <URL> -o file.txt
[Append output] — curl <URL> >> file.txt
[Show headers + body] — curl -i <URL>
---- Proxy -----
[HTTP proxy] — curl -x http://127.0.0.1:8080 <URL>
[SOCKS5 proxy] — curl --socks5 127.0.0.1:9050 <URL>
---- Methods -----
[PUT] — curl -X PUT -d "data=test" <URL>
[DELETE] — curl -X DELETE <URL>
[OPTIONS] — curl -X OPTIONS <URL>
---- Speed / Rate -----
[Limit speed] — curl --limit-rate 200k <URL>
[Timeout] — curl --max-time 10 <URL>
---- Debug -----
[Trace] — curl --trace trace.txt <URL>
[Trace ASCII] — curl --trace-ascii debug.txt <URL>
---- Useful -----
[Follow redirects] — curl -L <URL>
[IPv4 only] — curl -4 <URL>
[IPv6 only] — curl -6 <URL>
[Download multiple URLs] — curl -O <URL1> -O <URL2>
wgetDownload files and mirror sites
---- Common -----
[Télécharger simple] — wget <URL>
[Télécharger dans un fichier spécifique] — wget -O file.txt <URL>
[Télécharger en mode verbose] — wget -v <URL>
[Télécharger silencieux] — wget -q <URL>
---- Headers / User-Agent -----
[User-Agent custom] — wget --user-agent="Mozilla/5.0" <URL>
[Ajouter header] — wget --header="Host: admin.local" <URL>
[Ignorer certificat SSL] — wget --no-check-certificate https://<URL>
---- Auth -----
[Basic Auth] — wget --user=user --password=pass <URL>
[Cookie injection] — wget --header="Cookie: session=abc123" <URL>
---- Proxy -----
[HTTP proxy] — wget -e use_proxy=yes -e http_proxy=http://127.0.0.1:8080 <URL>
[Désactiver proxy] — wget -e use_proxy=no <URL>
---- Recursive -----
[Téléchargement récursif] — wget -r <URL>
[Récursif + pas de parent] — wget -r --no-parent <URL>
[Récursif + niveau] — wget -r -l 2 <URL>
[Mirror complet] — wget -m <URL>
---- Speed / Rate -----
[Limiter vitesse] — wget --limit-rate=200k <URL>
[Timeout] — wget --timeout=10 <URL>
---- Output -----
[Log dans fichier] — wget -o log.txt <URL>
[Append log] — wget -a log.txt <URL>
---- FTP -----
[FTP simple] — wget ftp://<IP>/file.txt
[FTP avec user/pass] — wget ftp://user:pass@<IP>/file.txt
---- Useful -----
[Télécharger liste d’URL] — wget -i urls.txt
[Forcer IPv4] — wget -4 <URL>
[Forcer IPv6] — wget -6 <URL>
PostmanTest and debug APIs with custom requests
---- Common -----
[Nouvelle requête] — Create a new POST request to http://<IP>/api/login
[Body JSON] — Body > raw > JSON: {"user":"admin","pass":"password"}
---- Options utiles -----
[Variable d'environnement] — Set {{base_url}} = http://<IP>
[Auth Bearer token] — Authorization tab > Bearer Token
[Collection Runner] — Run entire collection with Collection Runner
[Générer du code] — Code icon > choisir langage (curl, python, etc.)
jwt_toolInspect and tamper with JWT tokens
---- Common -----
[Analyser un token] — python jwt_tool.py <JWT_TOKEN>
[Mode playbook (tous tests)] — python jwt_tool.py <JWT_TOKEN> -M pb
---- Attaques -----
[Alg none] — python jwt_tool.py <JWT_TOKEN> -X a
[Confusion RS/HS256] — python jwt_tool.py <JWT_TOKEN> -X k -pk public.pem
[Cracker le secret] — python jwt_tool.py <JWT_TOKEN> -C -d <wordlist>
---- Forge -----
[Modifier un claim] — python jwt_tool.py <JWT_TOKEN> -T
[Signer avec secret connu] — python jwt_tool.py <JWT_TOKEN> -S hs256 -k secret
