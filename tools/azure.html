Azure CLI

ToolDescription
Account & RBAC Login, subscriptions, role assignments
---- Common -----
[Login] — az login
[Current account] — az account show
[List subscriptions] — az account list -o table
[Set subscription] — az account set --subscription <id>
---- RBAC audit -----
[List role assignments] — az role assignment list --all -o table
[Assignments for a user] — az role assignment list --assignee <user>
[Owners at subscription scope] — az role assignment list --role Owner --scope /subscriptions/<id>
[Custom role definitions] — az role definition list --custom-role-only true
Resources Groups, VMs, list/inspect
---- Common -----
[List resource groups] — az group list -o table
[List all resources] — az resource list -o table
[List VMs] — az vm list -o table
[VM status] — az vm get-instance-view --name <vm> --resource-group <rg>
[Start VM] — az vm start --name <vm> --resource-group <rg>
[Stop/deallocate VM] — az vm deallocate --name <vm> --resource-group <rg>
Storage Accounts, containers, public access
---- Common -----
[List storage accounts] — az storage account list -o table
[List containers] — az storage container list --account-name <account>
[List blobs] — az storage blob list --account-name <account> --container-name <container>
---- Audit -----
[Public access level] — az storage account show --name <account> --query allowBlobPublicAccess
[Container public access] — az storage container show --name <container> --account-name <account> --query properties.publicAccess
[Firewall/network rules] — az storage account network-rule list --account-name <account>
[Encryption status] — az storage account show --name <account> --query encryption
Key Vault & secrets Secrets, keys, access policies
---- Common -----
[List vaults] — az keyvault list -o table
[List secrets] — az keyvault secret list --vault-name <vault>
[Show secret value] — az keyvault secret show --vault-name <vault> --name <secret> --query value
[Access policies] — az keyvault show --name <vault> --query properties.accessPolicies
[Firewall rules] — az keyvault network-rule list --name <vault>
Logging & audit Activity log, Defender for Cloud
---- Activity log -----
[Recent activity] — az monitor activity-log list --max-events 20
[Filter by resource group] — az monitor activity-log list --resource-group <rg> --max-events 20
---- Defender for Cloud -----
[Security assessments] — az security assessment list
[Secure score] — az security secure-scores list
