File searchFinding files commands
---- Recherche un fichier -----
[Trouver un fichier contenant un mot] — find / -type f -name "*flag*" 2>/dev/null
[Trouver par extension] — find / -type f -name "*.txt" 2>/dev/null
---- Search for IP address -----
[Trouver fichiers contenant une IP] — grep -RlE "([0-9]{1,3}\.){3}[0-9]{1,3}" /chemin 2>/dev/null
[Voir lignes contenant une IP] — grep -RniE "([0-9]{1,3}\.){3}[0-9]{1,3}" /chemin
---- Get info on file -----
[Voir infos complètes] — stat /file
[Trouver fichiers exécutables par tous] — find / -type f -perm -o=x 2>/dev/null
[Trouver fichiers 755] — find / -type f -perm 755 2>/dev/null
---- Nombre de lignes -----
[Compter lignes] — wc -l /fichier.txt
[Compter lignes (output propre)] — wc -l < /fichier.txt
---- Trouver le SHA1 HASH du fichier -----
[SHA1] — sha1sum /fichier
[SHA256] — sha256sum /fichier
---- SUID Files (Privilege Escalation) -----
[Trouver fichiers SUID] — find / -type f -perm -4000 2>/dev/null
[Trouver fichiers SUID + exécutables] — find / -type f -perm -u=x -perm -4000 2>/dev/null
---- SGID Files -----
[Trouver fichiers SGID] — find / -type f -perm -2000 2>/dev/null
---- World-Writable Files -----
[Fichiers modifiables par tout le monde] — find / -type f -perm -o=w 2>/dev/null
[Dossiers modifiables par tout le monde] — find / -type d -perm -o=w 2>/dev/null
---- Executable Files -----
[Trouver fichiers exécutables] — find / -type f -executable 2>/dev/null
[Trouver fichiers exécutables par others] — find / -type f -perm -o=x 2>/dev/null
---- Search Inside Files -----
[Chercher un mot dans les fichiers] — grep -Rni "mot" /chemin 2>/dev/null
[Chercher un motif regex] — grep -RniE "regex" /chemin 2>/dev/null
---- File Type Identification -----
[Identifier type du fichier] — file /chemin/fichier
[Voir contenu lisible d’un binaire] — strings /chemin/fichier
---- File Size / Sorting -----
[Lister fichiers par taille] — find / -type f -exec ls -lh {} \; | sort -k5 -h
[Trouver fichiers > 10MB] — find / -type f -size +10M
Git dumpExploiter une fuite .git
---- Télécharger le .git -----
[Télécharger .git] — wget -r -np -nH --cut-dirs=1 http://site/.git/
[Rebuild repo] — git reset --hard
---- Lister les objets -----
[Lister objets] — find .git/objects -type f
[Construire SHA‑1] — dossier + nom_fichier → ex: 25/abcd → SHA1 = 25abcd
---- Vérifier type d’objet -----
[Type] — git cat-file -t SHA1
[Chercher blobs] — git cat-file -t [SHA1] | grep blob
---- Lire le contenu -----
[Afficher blob] — git cat-file -p [SHA1]
[Chercher flag] — git cat-file -p [SHA1] | grep -i flag
---- Trouver objets cachés -----
[Objets non référencés] — git fsck --lost-found
[Commits supprimés] — git log --all --oneline
---- Résumé stratégique -----
[Flag souvent ici] — blobs non référencés (pas dans index, pas dans HEAD)
[Ne pas utiliser] — index.html dans objects/ = FAUX fichiers générés par le serveur
