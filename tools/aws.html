AWS CLI

ToolDescription
Identity & IAM Who am I, users, policies, keys
---- Common -----
[Who am I] — aws sts get-caller-identity
[List users] — aws iam list-users
[List roles] — aws iam list-roles
[User's policies] — aws iam list-attached-user-policies --user-name <user>
[Policy document] — aws iam get-policy-version --policy-arn <arn> --version-id v1
---- Audit -----
[Users with console access, no MFA] — aws iam generate-credential-report && aws iam get-credential-report
[Access keys age] — aws iam list-access-keys --user-name <user>
[Simulate permission] — aws iam simulate-principal-policy --policy-source-arn <arn> --action-names <action>
[Unused roles (IAM Access Analyzer)] — aws accessanalyzer list-findings --analyzer-arn <arn>
S3 Buckets, objects, public access
---- Common -----
[List buckets] — aws s3 ls
[List objects] — aws s3 ls s3://<bucket>/
[Sync] — aws s3 sync . s3://<bucket>/
[Copy] — aws s3 cp <file> s3://<bucket>/
---- Audit -----
[Public access block] — aws s3api get-public-access-block --bucket <bucket>
[Bucket policy] — aws s3api get-bucket-policy --bucket <bucket>
[Bucket ACL] — aws s3api get-bucket-acl --bucket <bucket>
[Encryption config] — aws s3api get-bucket-encryption --bucket <bucket>
[Versioning status] — aws s3api get-bucket-versioning --bucket <bucket>
EC2 & network Instances, security groups
---- Common -----
[List instances] — aws ec2 describe-instances
[Running instances only] — aws ec2 describe-instances --filters "Name=instance-state-name,Values=running"
[Start instance] — aws ec2 start-instances --instance-ids <id>
[Stop instance] — aws ec2 stop-instances --instance-ids <id>
---- Security groups -----
[List security groups] — aws ec2 describe-security-groups
[SGs open to 0.0.0.0/0] — aws ec2 describe-security-groups --filters Name=ip-permission.cidr,Values='0.0.0.0/0'
[Revoke ingress rule] — aws ec2 revoke-security-group-ingress --group-id <sg> --protocol tcp --port <port> --cidr 0.0.0.0/0
Logging & audit CloudTrail, GuardDuty, Config
---- CloudTrail -----
[List trails] — aws cloudtrail describe-trails
[Trail status] — aws cloudtrail get-trail-status --name <trail>
[Lookup events] — aws cloudtrail lookup-events --max-results 20
---- GuardDuty -----
[List detectors] — aws guardduty list-detectors
[List findings] — aws guardduty list-findings --detector-id <id>
---- Config -----
[Compliance by rule] — aws configservice describe-compliance-by-config-rule
Engagement setup Profiles, MFA session
---- Common -----
[Configure profile] — aws configure --profile <name>
[Use a profile] — aws s3 ls --profile <name>
[Assume role] — aws sts assume-role --role-arn <arn> --role-session-name <name>
[MFA session token] — aws sts get-session-token --serial-number <mfa-arn> --token-code <code>
